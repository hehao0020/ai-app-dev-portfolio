# 何圣荣 · AI 应用开发作品集

面向 AI 应用开发（Agent / 全栈）岗位。独立静态站点。

- 轻稿：Electron 桌面应用、模型 API、本地检索、排版与导出。
- 张嘴就记：微信小程序、语音识别云函数、本地解析与失败处理。
- GEO Brand Monitor：模型调用、异常分类、CSV 报表与离线测试。
- 稿件检查 Agent：可交互的本地规则编排，包含工具选择、失败重试、用户确认和报告下载。

直接打开 index.html，或运行 `python -m http.server 8771` 后访问 `http://localhost:8771`。页面和演示无运行时依赖。截图与录屏为公开作品集的展示素材。
