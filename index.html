Windows 桌面应用

轻稿

输入一个标题，生成完整正文并排成可编辑卡片。实机演示约 12 秒生成 9 张卡片。

  • Electron
  • JavaScript / Node.js
  • 模型 API
  • 本地文件存储
  1. 标题输入
  2. 检索写法
  3. 模型生成
  4. 本地排版
  5. 检查与导出
实现与关键取舍
  • 编辑器通过 preload 的有限接口调用主进程。主进程校验调用来源，负责模型请求、密钥保存和文件写入。
  • 生成前检索本地写法档案，模型返回文本后由编辑器解析、分页。查词规则在本机运行，命中明显风险时尝试改写，仍有风险时保留预览。
  • 生成期间若文稿或页面发生变化，停止覆盖并保留返回结果。采用后可撤销，导出前可查看溢出和图片加载提示。

验证 · 13 项 Node 自动化测试通过。右侧录屏展示真实模型接入和实际生成过程，剪去部分等待。

已上线微信小程序

张嘴就记

把一句话拆成待确认的账目、记事、物品或打卡记录，确认后批量保存。

  • 微信原生小程序
  • 微信云开发
  • 腾讯云 ASR
  • 本地存储
  1. 录音
  2. 语音转文字
  3. 解析与归类
  4. 逐条确认
  5. 批量保存
实现与关键取舍
  • 语音转文字支持微信同声传译插件或云函数。云函数对接腾讯云一句话识别，识别文本再由本地规则归类。基础手填可独立使用。
  • 同一句话可能有多类记录。待记清单按条目打开对应编辑表单，切换行之前先保留当前修改。
  • 批量写入前逐条校验。部分写入失败时保留失败项，重试只针对尚未保存的内容，避免已成功条目重复入账。

验证 · 发布前记录包含 305 项自动化测试、23 个微信模拟器场景。语音云函数测试使用模拟请求。

开源模型评测工具

GEO Brand Monitor

固定一组问题调用 DeepSeek，将品牌字面提及、未提及与请求失败分别写入 CSV。

  • Python
  • OpenAI 兼容 SDK
  • DeepSeek API
  • pandas
  1. 固定问题
  2. 独立请求
  3. 校验响应
  4. 判断提及
  5. CSV 落盘
实现与关键取舍
  • 每个问题使用独立上下文。报告保留模型、请求时间、问题是否预含品牌词和错误类型，方便后续复跑和比较。
  • 空回复、超时和未正常结束的回复记为 Error。有效响应再分别标记 Positive 或 Missed，其中 Positive 仅表示出现了字面品牌词。
  • 每完成一条就写入临时文件并替换报表。对模型输出做 CSV 公式转义，便于在表格软件中打开。

验证 · 项目记录包含 8 项离线测试，使用真实 SDK 和模拟 HTTP 响应。
